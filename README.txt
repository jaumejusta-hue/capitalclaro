PUBLICAR EN GITHUB PAGES (GRATIS):
1. Crea una cuenta en https://github.com/ si todavía no tienes.
2. Pulsa New repository.
3. Nombre recomendado: capitalclaro (o capitalclaro-web).
4. Selecciona Public y crea el repositorio.
5. Add file > Upload files y sube todos los archivos y carpetas de esta carpeta, conservando la estructura.
6. Pulsa Commit changes.
7. En el repositorio, Settings > Pages.
8. En Build and deployment selecciona Deploy from a branch; branch main y folder /(root); Save.
9. Espera a que GitHub publique y abre la URL que aparece en Settings > Pages.

IMPORTANTE:
- El repositorio y el sitio publicado son públicos; no subas contraseñas ni datos privados.
- GitHub Pages ofrece hosting estático; no ejecuta PHP, Python ni bases de datos de servidor.
- Las páginas legales son plantillas, NO asesoramiento legal. Completa los campos entre corchetes y adáptalas a tus tratamientos de datos y obligaciones reales.
- Antes de AdSense, revisa la elegibilidad actual. Google requiere contenido propio de calidad, cumplimiento de políticas y control del código. Las URLs github.io son subdominios y Google indica que los subdominios admitidos para alta directa se limitan a plataformas host partner; puede ser necesario un dominio propio.
- Para contenido financiero, verifica cifras y afirmaciones con fuentes oficiales, añade autoría y fecha de revisión, evita promesas de rentabilidad y no presentes contenido educativo como asesoramiento personalizado.
